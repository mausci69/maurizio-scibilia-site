Released application · Available on the App Store

ParancU for iOS

I developed and released ParancU for iOS, a mobile application featuring AI-assisted document preparation and on-device multilingual retrieval.

Building on the EcoSearch research prototype, I took the project through research framing, architecture, implementation, benchmark design, failure analysis, mobile integration and App Store release. Corpus persistence, multilingual E5 inference, scoring, ranking and evidence inspection run on-device, with lexical signals available when exact or rare terms matter.

The v1.1 white paper documents the implementation, evaluation results and remaining limitations.

Experimental web application

ParancU Agent Lab

I subsequently developed ParancU Agent Lab, an experimental web application exploring document retrieval, AI-assisted generation and verification workflows.

Prepared ParancU corpora can be searched directly in the browser without an API key. Optional server-assisted generation and verification steps provide a way to investigate how retrieved passages support an answer and where information may be missing. These workflows remain experimental and do not guarantee factual correctness or complete evidence.

From EcoSearch to ParancU

The project evolved by questioning the retrieval objective itself.

Earlier work

EcoSearch

EcoSearch began as a retrieval-first QA prototype designed to make supporting passages visible before generation.

It became a test bed for chunking, semantic search, lexical signals, reranking, confidence routing and retrieval evaluation.

Research context

Evidence-oriented retrieval

Those experiments exposed a more fundamental question: semantic proximity is useful, but does it reliably identify the passage containing the evidence needed to answer a question?

ParancU focuses directly on that retrieval problem, independently from downstream language generation.
